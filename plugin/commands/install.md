---
description: Установка агента делегирования: печатает команду для терминала (токен вводится только там)
---
Ответь ровно этим блоком и больше ничего. Ничего не запускай, не вызывай инструменты.

Скопируйте нужную строку в терминал. Токен вводится там скрытым вводом и в этот чат не попадает.

С расписанием (раз в минуту):
```
node "${CLAUDE_PLUGIN_ROOT}/bin/shar8-agent.mjs" install --schedule
```

Без расписания (запуск вручную командой run):
```
node "${CLAUDE_PLUGIN_ROOT}/bin/shar8-agent.mjs" install
```
