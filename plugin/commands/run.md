---
description: Один ручной проход агента делегирования: печатает команду run
---
Ответь ровно этим блоком и больше ничего. Ничего не запускай, не вызывай инструменты.

Mac и Linux:
```
node ~/.config/shar8-agent/shim.mjs run
```

Windows (beta):
```
node "%LOCALAPPDATA%\shar8-agent\shim.mjs" run
```
