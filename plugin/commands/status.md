---
description: Состояние агента делегирования: печатает команду status
---
Ответь ровно этим блоком и больше ничего. Ничего не запускай, не вызывай инструменты.

Mac и Linux:
```
node ~/.config/shar8-agent/shim.mjs status
```

Windows (beta):
```
node "%LOCALAPPDATA%\shar8-agent\shim.mjs" status
```
