---
description: Снять расписание агента делегирования: печатает команду uninstall
---
Ответь ровно этим блоком и больше ничего. Ничего не запускай, не вызывай инструменты.

Mac и Linux:
```
node ~/.config/shar8-agent/shim.mjs uninstall
```

Windows (beta):
```
node "%LOCALAPPDATA%\shar8-agent\shim.mjs" uninstall
```
