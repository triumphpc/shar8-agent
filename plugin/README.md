# Плагин делегирования shar8 для Claude Code

Плагин забирает из shar8 задачи, которые вы пометили «Агенту», запускает для каждой агента Claude Code и кладёт результат в заметки задачи: статус «На проверке» или «Нужно уточнение». Задачу закрываете только вы. Если делегированных задач нет, модель не вызывается вовсе.

Модель работает на вашей подписке Claude Code или на вашем ключе `ANTHROPIC_API_KEY`: режим вы выбираете сами при установке, значения по умолчанию нет. Единственный канал к shar8 — MCP по HTTPS (`TASKFLOW_MCP_URL`) с вашим личным токеном; других адресов у плагина нет.

## Что проверено

| Платформа | Статус |
|---|---|
| Mac | вживую, 1 ноября 2026, но против локальной заглушки сервера и поддельного `claude`: установка плагина из каталога-кандидата, установка из терминала без расписания, `status`, `run` на пустой очереди (код 0), `uninstall`, обновление до следующей версии; launchd принял и снял файл задания, который генерирует плагин. Запуск модели (`claude -p`) вживую не проверен ни из терминала, ни по расписанию, ни с реальным сервером. Запуск по расписанию с вашей подпиской и вход из планировщика вживую ещё не проверены. Эталон `init` не сверен с настоящим `claude`. Слэш-команда `/shar8-agent:install` в живой сессии не запускалась |
| Linux | реализован, вживую **не проверен** (проверено файлами и подделками; CI-workflow написан, его прогон на GitHub ещё не выполнен) |
| Windows | **beta**: реализовано, вживую не проверено, шагов установки здесь нет |

Перезагрузка и сон Mac проверяются отдельно по списку владельца и в таблицу не входят.

## Требования

- Claude Code 2.1.308 или новее (`claude --version`);
- Node.js 20 или новее;
- личный токен shar8: в кабинете нажмите «Выдать токен» и сразу «Скопировать», токен виден один раз.

## Установка (Mac и Linux)

1. Поставьте плагин:

   ```sh
   claude plugin marketplace add triumphpc/shar8-agent
   claude plugin install shar8-agent@shar8
   ```

2. В сессии Claude Code выполните `/shar8-agent:install` и вставьте напечатанную строку в терминал. Слэш-команда ничего не запускает: она только печатает строку, поэтому токен через модель не проходит. Если слэш-команда недоступна, выполните в терминале `node "<installPath>/bin/shar8-agent.mjs" install`, где `<installPath>` — путь плагина из `claude plugin list --json`.
3. Установка в терминале спросит адрес сервера (Enter оставляет адрес по умолчанию), токен (скрытый ввод), режим модели и нужно ли расписание. В конце она делает пробный запуск `claude` («ответь ok») и прямо говорит, если проба не дошла.

Токен хранится в файле `env` с правами 0600. Он не попадает в аргументы командной строки, в `settings.json` и в `~/.claude.json`.

Расписание доступно всем: установка по умолчанию предлагает запуск раз в минуту. Без него плагин запускается вручную командой `run`.

## Управление

```sh
node ~/.config/shar8-agent/shim.mjs status
node ~/.config/shar8-agent/shim.mjs run
node ~/.config/shar8-agent/shim.mjs uninstall
```

- `status` показывает состояние плагина, расписание, время последнего запуска, паузу и её причину, версии, состояние `send-policy.json` и возраст сборки; `status --json` печатает то же машиночитаемо.
- `run` делает один ручной проход: опрашивает очередь и обрабатывает до трёх задач.
- `uninstall` снимает расписание и не трогает токен; повторный вызов безвреден. `uninstall --purge` после подтверждения удаляет и env-файл.
- `policy` проверяет `send-policy.json`: печатает `empty`, `ok` или код причины и путь первой ошибки без значений.

Обновление:

```sh
claude plugin marketplace update shar8
claude plugin update shar8-agent@shar8
```

Таймер вызывает стабильный shim по пути выше, поэтому обновление плагина его не ломает; `status` после обновления видит новую версию.

## Режимы модели

- `subscription` — ваша подписка Claude Code (вход `claude.ai`). Из планировщика launchd на Mac подписка проверена вживую 2026-11-02 (реальный сервер shar8.app, настоящий `claude`); если проба не прошла, выберите режим `key` и повторите `install`.
- `key` — ваш `ANTHROPIC_API_KEY`. Ключ вводится скрытым вводом и хранится только в env-файле.

Режимы не смешиваются: режим `subscription` с заполненным ключом — ошибка конфигурации.

## Лимит и расписание

На Free — 5 запусков в месяц. Расписание, раз в минуту, доступно на любом тарифе: сервер ограничивает только число запусков, а не расписание. Запуск вручную — командой `run`. Лимит считает сервер, плагин его не знает и не хранит. Исчерпанный лимит плагин видит как отказ сервера и час не берёт задачи, но продолжает читать очередь.

## Что агент может

По умолчанию у агента нет инструментов: он видит только текст задачи и отвечает текстом. Расширить его можно только двумя файлами в каталоге `~/.config/shar8-agent/`.

### `agent.json`: чтение

```json
{
  "version": 1,
  "mcpServers": ["tracker"],
  "tools": ["Read"],
  "allowedTools": ["mcp__tracker__get_issue", "mcp__tracker__search_issues"]
}
```

- `mcpServers` — имена серверов из пользовательских настроек Claude Code (`claude mcp add -s user`). Серверы области `local` и `project`, коннекторы claude.ai и MCP-серверы плагинов не поддерживаются.
- `tools` — только встроенные `Read`, `Glob`, `Grep`. `Bash`, `Write`, `Edit`, `WebFetch` и остальное закрыты: иначе агент мог бы прочитать env-файл с токеном.
- `allowedTools` — точные имена `mcp__<сервер>__<инструмент>`; префиксы, `*` и голое имя сервера отвергаются.

Пример с веб-поиском. Имена `web-search` и `search` условные: подставьте свои, посмотреть их можно командой `claude mcp list`.

```json
{
  "version": 1,
  "mcpServers": ["web-search"],
  "tools": [],
  "allowedTools": ["mcp__web-search__search"]
}
```

Ловушка: без `agent.json` агент не ходит в интернет, и задача вроде «узнай погоду» заканчивается статусом «Агент не справился». Если агенту нужен поиск, подключите MCP-сервер поиска на уровне user и впишите его сюда.

Любое нарушение схемы даёт ошибку конфигурации (код 78): `claude` не запускается, в сообщении только код и путь ключа, без значений. Защита env-файла от чтения агентом держится на двух вещах: запрещающих правилах `Read(//<абс. путь>/**)` и `blockReadsOutsideWorkingDirectories`. Живая проверка `Glob` и `Grep` не делалась: на них как на защиту не рассчитывайте.

### `send-policy.json`: отправка

Файла нет или он пуст — агент ничего не отправляет. Чтобы разрешить отправку, опишите инструменты и белые списки адресатов; файл должен быть обычным файлом с правами 0600 вашего владельца и не больше 64 КиБ. Любая ошибка закрывает отправку (хук gate отказывает), проверить файл можно командой `policy`.

```json
{
  "version": 2,
  "tools": {
    "mcp__chat__send_message": { "slot": "chat_message", "list": "chats", "target": [["chat_id"]], "text": [["text"]], "fields": [], "extract": "identity" }
  },
  "allow": { "chats": ["<id чата>"] },
  "limits": { "chat_message": 3 }
}
```

- Адресат сверяется с `allow` точно, без нормализации. Составные адресаты (`to`, `cc`, `bcc`) проверяются все.
- Входы инструмента, не объявленные в `target`, `text` или `fields`, отвергаются.
- Строка текста, начинающаяся с `/`, отвергается (быстрые действия в комментариях). Отключается только явно через `checks_off`.
- Потолки действуют на один запуск, файл может только уменьшить их (не больше 20 на слот и 20 всего).
- Постановка задачи считается вашим явным запросом: предпросмотра и подтверждения нет.
- После запуска в заметке агента первым блоком идёт журнал действий: выполнено, заблокировано, упало или начато без подтверждённого итога. После прерванного запуска проверьте отправленное вручную.

Файл с примером: `examples/send-policy.example.json`.

## Паузы и коды выхода

| Событие | Что делает плагин |
|---|---|
| сеть недоступна, ошибка 5xx, сон | тихо выходит, код 0, повторит на следующем тике |
| пустая очередь | модель не вызывается, код 0 |
| отказ в доступе (401, 403) | пауза 10 минут; код 77 на самом отказе |
| лимит Free, «нужен Pro» | пауза на взятие задач 1 час, очередь читается |
| нет входа в `claude`, нет ключа, режим не совпадает со входом | пауза 5, 10, 20, 40, потом 60 минут; код 78 |
| ошибка `agent.json`, env-файла или режима модели | до обращения к сети; код 78 |
| `send-policy.json` нечитаем или слишком открыт | запуск идёт в режиме чтения, отправка закрыта |

Коды: `0` штатно или тихо, `77` отказ в доступе, `78` ошибка конфигурации или окружения, `1` прочее.

Лимиты запуска: до 3 задач за проход, 15 минут на задачу, 30 ходов, бюджет 2.00 USD на задачу.

## Файлы на машине

| Что | Mac и Linux | Права |
|---|---|---|
| env (адрес, токен, режим) | `~/.config/shar8-agent/env` | 0600 |
| `agent.json`, `send-policy.json` | `~/.config/shar8-agent/` | 0600 |
| shim, загрузчик | `~/.config/shar8-agent/shim.mjs`, `tick.sh` | 0644, 0755 |
| состояние (`heartbeat.json`, `backoff.json`, пробы) | `~/.local/state/shar8-agent/` | 0600 |
| каталоги запусков, замок | `~/.local/state/shar8-agent/` | 0700, хранение 14 дней |
| лог тика | Mac `~/Library/Logs/shar8-agent/tick.log`; Linux journald | каталог 0700 |
| задание планировщика | Mac `~/Library/LaunchAgents/com.shar8.agent.plist`; Linux `~/.config/systemd/user/shar8-agent.{service,timer}` | 0644 |

Самоснятие расписания, когда плагин удалён (на Mac `bootout` из отсоединённого процесса, в задании стоит `AbandonProcessGroup`), вживую не проверено: для надёжного снятия используйте `uninstall` до удаления плагина.

Windows (beta): пути лежат в `%LOCALAPPDATA%\shar8-agent\`, планировщик — задача `\Shar8Agent`.

## Безопасность и приватность

- Токен вводится скрытым вводом в терминале и хранится только в env-файле; в логи и выводы он не попадает.
- Процесс `claude` запускается с изоляцией: пустой список инструментов по умолчанию, `--permission-mode dontAsk`, свой набор MCP-серверов только из `agent.json`, окружение по белому списку (без `TASKFLOW_*`).
- К серверу shar8 плагин обращается только вызовами `agent_queue`, `agent_claim` и `agent_finish`; запросы несут заголовок `User-Agent: shar8-agent/<версия>`.
- Текст задачи передаётся агенту через stdin, не через аргументы.

## Разработка

Тесты плагина: `node scripts/run-plugin-tests.mjs`. Файлы `plugin/runtime/vendor/` — копии общего кода приложения, обновляются скриптом `scripts/sync-plugin-vendor.mjs`; страж проверяет совпадение. Текст команд для README, слэш-команд и страницы приложения берётся из `runtime/cli-constants.mjs`.
